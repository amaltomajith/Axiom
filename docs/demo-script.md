# Two-minute demo

Run the backend with `TRADER_BRAIN=desk` and open `/app`. Everything below is on the Autopilot tab. The account is
paper only.

| Time | Do | Say |
|---|---|---|
| 0:00 | Point at the PAPER badge, the autonomy ladder and the risk meters | "It trades a paper account. It starts supervised and has to earn more freedom." |
| 0:15 | Press **Review BTC/USD now** on the Live run card | "Four agents now research Bitcoin through MCP tools. Watch each step arrive." |
| 0:40 | Press **Read the full review** | "This is everything they did: each tool call, each claim with the evidence it cites, the case for against the case against, and the Critic's objections." |
| 1:00 | Scroll to **What the desk did with it** | "A fixed rule turns the rating into go, half size or refuse. The agents never set a quantity." |
| 1:10 | Point at **Policy gate, six checks** and the Approvals card if an entry is waiting | "Plain code decides whether an order may go out. In supervised mode I approve it." |
| 1:25 | In Time Machine press **Play Flash crash** | "Real history. The daily loss limit trips at 2.5%, everything is sold and trading stops." |
| 1:40 | Press the **Kill switch**, then release it | "One button flattens everything." |
| 1:50 | Scroll to **Trades not taken** | "Every trade the desk refuses is tracked and graded too, so we can say whether saying no was right." |

If the network or the free models are down, press **Play a recorded review**. It opens a real review saved from this
system, marked as recorded.

Honest lines to keep ready:

- The agents do not chat freely. Two analysts work in parallel, the Synthesizer argues both sides from their
  findings, and the Critic challenges the plan once.
- The rule strategies have not beaten buy-and-hold in the backtest (see `docs/backtest-report.md`). What the system
  offers is control: smaller drawdowns, hard limits, and a record of every decision, including the ones not taken.
- A review takes from half a minute to four minutes and is capped at six per hour.
